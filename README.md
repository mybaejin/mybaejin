1. 중고 스위치를 구매 그리고 내부망을 구축하여 내부 모의 공격하여 방어 방법을 연구
   1-1. ARP 스푸핑 등 네트워크 패킷 관련 처리 소프트웨어를 `C#`으로 직접 개발하고 방어 방법 연구

4. 3D 캐릭터를 직접 제작하고 텍스처, UV 맵핑 등의 과정 수행, `C++` 기반 DirectX 9 또는 `OpenGL`, `ThreeJS`에서 각종 수식을 연산하여 쉐이더 및 3D 캐릭터 애니메이션 구현
5. `Java`로 RSA, AES 기반 네트워크 암호화 통신 라이브러리 개발

9. `Java` `JS` `MariaDB` 기반 네트워크 터널링, 포트 터널링 소프트웨어 개발
